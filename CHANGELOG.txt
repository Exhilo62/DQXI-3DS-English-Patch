DQXI 3DS English patch - changelog
==================================
  * Two ways to play on a real 3DS - use ONE, never both:
    A) RECOMMENDED / safest: make a NEW full patched .cia / .3ds from the newest version and install that (everything is translated).
       Delete any old Luma folder first (SD:/luma/titles/0004000000199200).
    B) Luma folder (back in 0.1.28): only on a fresh, UNMODIFIED Japanese install of the game. Delete the old
       SD:/luma/titles/0004000000199200 and copy the new "luma" folder over it with EVERY update, with "Enable game patching" on.
       CAUTION: a folder is NOT a complete translation. It cannot change the game program, so the battle command menu (Fight / Plan / Swap / Flee,
       Attack / Spells / Defend / Ability / Items / Equip), the party / bench / bag labels, the status abbreviations (KO / Psn / Cur) and the HOME-menu
       banner stay Japanese (list: LUMA_FOLDER_LIMITS.txt in the download).
       NOTE: folders are offered for people who do not want to reinstall for every test version. If they become a known problem again they
       will be switched off until the project is nearly complete. Code changes can only ever be in the full .cia / .3ds, never in a folder.
    A patched game plus a Luma folder, or several patched versions installed over each other, can crash in battle.

0.1.21
  * Party names redrawn + SAVE REPAIR TOOL. In 0.1.20 the two letters that share one character in "Veronica" and "Sylvando" were drawn too small in battle messages ("Veronic" + a tiny "a"). The game shrinks the last character of a name and the battle text font keeps each letter's outline, so two full letters did not fit. The pairs now sit earlier in the name ("Ve"+ro+ni+"ca", "Sy"+lv+an+"do"), the last letter is a normal one, and the battle-message font squeezes the pair smoothly. Both names read correctly in battle messages, the party panel and menus. The "a" and "n" of Sylvando sit a little closer than other letters because two letters share one character; this cannot be spaced wider.
  * WHO MUST DO SOMETHING: the names are stored in the save. A NEW game started with 0.1.21 is fine. A save made with 0.1.17 - 0.1.20 holds the old form (7 letters "Veronic"/"Sylvand", or the 0.1.20 two-letter form) and will show wrong letters or a stray symbol in the names until it is repaired. Use the separate download "DQXI_3DS_Save_Repair" on a COPY of your save (README inside; it keeps your originals in a backup folder), then play with a game patched with 0.1.21 or newer. It converts both the 7-letter names and the 0.1.20 names.
  * Why 7 letters were a problem: the save's name field holds only 6 characters plus an end marker, so the 7th letter ran into the next field. That explains the stray symbol after "Veronic" in some lists and "Veronic ,Serena" in the Link requirements. It is also the likely cause of an Old 3DS crash a tester has (Veronica in the 4th slot, everyone on Manual, choosing each attack): the same save also crashed the unmodified Japanese game, so it is not a translation bug. Whether repairing the names removes the crash is not confirmed yet; please tell us if it does or does not.

0.1.20
  * Crash fix (cutscenes, reported on GitHub by a player with an Old 3DS): in 0.1.19 the cutscene message timing change wrote a time value over a data field in two scenes, the Heliodor prison break and the Hekswood scene where Hendrik fights the monster Jormun. On a real 3DS this could crash the game or stop the dialogue from appearing. The timing change now skips that kind of field, so those two scenes keep their original data. If a cutscene still crashes, please tell us which one.
  * Cutscene timing (reported by testers: characters vanishing, a scene repeating its animation, music starting early, dialogue not appearing): the 0.1.19 timing change made scenes LONGER for the longer English text, but the characters and cameras are driven by data of the original length. This version no longer lengthens scenes at all: every line keeps its original start time and scene length, and a line is only kept on screen longer when the next line has not started yet. Some long lines may therefore close a little early; the reading time is the same as in the Japanese game.
