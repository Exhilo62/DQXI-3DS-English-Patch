DQXI 3DS English patch - changelog
==================================

0.1.11
  * Text overflow fixes: stats-menu title ("Equipment Effects"), item command
    window title ("What to do?"), skill descriptions (critical rate / "when
    attacking with ..."), Link description in battle, quest-log text no longer
    runs under the Reward bar, "Bodkin Archer" on the bottom screen.
  * Overhead speech bubbles: hand-typed "|" separators were drawn as "!" and are
    now real line breaks; about 70 bubbles re-wrapped to two lines.
  * Quest log descriptions fit above the Reward bar (smaller font, re-wrapped).
  * Item/forge command window title reads "What to do?" so it no longer wraps.
  * FIX (crash on real 3DS): opening the chest in the well near the tavern in Heliodor
    Castle Town (and anything that shows the Mystic Nut by name) crashed. A data field in
    the item table that merely looked like a text pointer was being overwritten by
    the patcher.
  * "Seed of Deftness" was wrongly named "Seed of Skill"; the skill-point seed is now "Seed of Skill".
  * FIX: about 600 spots in NPC dialogue and map tables had a data value (for example 0xFF00)
    overwritten by the patcher because it looked like a text pointer. This could make some
    dialogue boxes not open (e.g. Manolo's apology in Cobblestone) and similar glitches.
  * The patcher window now shows these patch notes.
  * Linux / Steam Deck / macOS: new "Linux" download (Python launcher, see README_LINUX.txt).
  * Silent NPC lines ("......") were drawn as "____"; they now show "...".
  * Map scroll label reads "Scrolling" instead of Japanese letters.
  * Known gaps in update folders (LayeredFS): the battle "Link" command label, the
    equip-window headers (L.H. / Items / Equip), the group-battle result wording
    ("<name>'s team receives ...") and 2D "examined" object names are still
    Japanese-looking. Changing these crashes real hardware when loaded this way.
0.1.10
  * FIX: "Create update folder" updates crashed on a real 3DS at the first battle
    (after leaving the church with Erik). The update folder now ships a code patch
    that the update mechanism (Luma LayeredFS) handles safely: it keeps the
    original menu string loads and uses short labels (Fight / Plan / Run, Hit /
    Spell / Guard / Art / Bag / Eq.). Patched .cia / .3ds files are unchanged and
    keep the full labels (Attack / Spells / Defend / Ability / Items / Equip).
  * The battle menu's third item and its pop-up now read "Swap" in update folders
    too (fixed in the font, no code change).
  * Known: the Plan menu's "Party" row is still unreadable in update folders; it
    reads "Party" in a full patched .cia.
0.1.9
  * FIX: crash in the Heliodor prison break with Erik (data abort on real 3DS).
    Two cutscene timing tables (a_020_cs_060, a_170_cs_050) had a value written over
    an ID field; restored. Confirmed on real 3DS hardware.
  * FIX: Records > Monster List showed almost nothing seen / empty log. A stray
    "text" at the start of every text table was being relocated, corrupting the
    monster data. All text tables are now rebuilt without it.
  * Monster List: descriptions re-wrapped to fit the box (smaller font, no more
    mid-word breaks), "Gold:" / "Defeated:" / "Items:" colons sit next to the
    labels, the Japanese counter after the defeat count now shows "X", and the
    "Other" habitat label fits.
  * NEW: "Create update folder (already patched game)" button. Make a small
    LayeredFS update (about 150 MB, copied to the SD card) instead of rebuilding and
    reinstalling the whole game. See README.

0.1.8
  * Item command window (Use / Give / Equip / Discard / Cancel + "What will you
    do?") is wider, so labels no longer clip or wrap onto each other.
  * Bottom-screen item description uses a smaller font so lines no longer break
    in the middle of words.
  * "Owned" box in shops has padding inside its border.
  * Bottom-screen item description no longer breaks a word in half
    ("A village greatsword").
  * FIX: crash in the shop Sell > Who? > Item Bag flow (Azahar and real 3DS). The
    item-detail panel layouts now keep their original sizes, and their small
    header labels are shortened to fit ("Drops", "Found", "Rar", "Perk" ...).
  * Confirmed on real 3DS hardware: shops (buy / sell, item bag) run without the
    crash reported earlier (fixed by the memory-footprint change in 0.1.7).

0.1.7
  * Much smaller memory footprint: the English text now reuses the space of the
    original Japanese text and shares identical strings, so the text tables are
    close to their original size (total growth over the game: 6.0 MB -> 1.0 MB).
    This is intended to fix the Heliodor 3D corruption (purple NPCs / black
    scene) reported on Azahar/Citra, and possible crashes on real 3DS hardware.
  * Campfire rest choice reads "AM" / "PM" (original-size window).
  * Inn choices read "Stay" / "Rest" / "Cancel" so they no longer overlap.

0.1.6
  * REAL 3DS FIX: some menu layouts were stored with section sizes that were not
    a multiple of 4 (introduced in 0.1.3). Emulators tolerated this, but a real
    3DS crashed with an "alignment" exception at startup. All 3,507 layouts are
    now aligned exactly like the original game.
  * Campfire rest choice now reads "AM" / "PM" so it fits the small window.

0.1.5
  * Battle results now read like the Switch version: "Eleven receives 6 experience
    points! / Eleven acquires 6 gold coins!", "Defeated the Slimes!", "The Slime
    drops a treasure chest!", "... puts the item in the item bag for safekeeping."
  * Field pickups: "(name) acquires <item>!" / "... 2 gold coins!" for chests, pots
    and barrels.
  * Item description strip in battle no longer overflows (smaller text, 52 long
    descriptions shortened).
  * Camp menu labels fit (Pray at Statue / Merchant); battle Plan menu "Party" row.
  * Level-up banner: "UP!!" spacing tightened.
  * Fixed stray line breaks after names ("Gemma / 's your childhood friend",
    "Gemma / ... ", "Cobblestone / .").
  * Animal cries (chicken, horse, dog ...) that were still Japanese are translated.
  * Movement hint reads "Top Screen: Use the Circle Pad to move. / Bottom Screen:
    Use the D-Pad to move."

0.1.4
  * Clear message when the input .cia/.3ds is still encrypted (instead of a cryptic
    "not an NCCH" error), with the GodMode9 decrypt steps.

0.1.3
  * Shop screens: "Buy" / "Sell" choices and the "Owned" label are now English.
  * About 1,500 remaining Japanese default labels in the layouts translated
    (item details, forge, StreetPass/Yocchi menus, profile, records, regions ...).
  * 2D fonts tightened; battle command window and 2D dialogue fit better.
  * Shop 'Owned' box: gap between the label and the count; item info/descriptions restored.
  * Fixed camp-menu / shop layouts that could show placeholder text or crash on hardware.

0.1.2
  * A decrypted .3ds can now be converted to an installable .cia (pick the output
    format in the tool).
  * HOME-menu banner shows "Echoes of an Elusive Age" instead of the Japanese
    subtitle; game title text is English.

0.1.1
  * One-click Windows tool (DQXIEnglishPatcher.exe): pick your .cia/.3ds, pick the
    output location; the result is named "Dragon Quest XI English.cia/.3ds".
  * Patches both .cia and .3ds files (decrypted input).
  * 2D mode: dialogue now wraps at word boundaries (narrower 2D font, line breaks
    fitted to both 2D and 3D fonts); battle command window fits (Attack / Spells /
    Defend / Ability / Items / Equip).
  * Official PS4/Switch monster names (Needler, Healslime, Mal./Vic. variants ...).
  * Camp menu: Items / Magic / Misc.; battle menu: Fight / Plan / Swap / Flee.
  * Character epithets shortened to fit the status panel; Luki is now Sandy.
  * Verified working on real 3DS hardware (.cia) and Citra/Azahar (.3ds).

0.1.0  (first public build)
  * Full UI, menus, battle, items, monsters, NPC and story text translated; map
    labels and town banners redrawn.
  * Official logo, Yes/No prompts, official character names.
  Known gaps: a few skipped NPC strings, the "Link available" texture, and some
  long monster names may overflow narrow boxes.
