# Name index: wording that is shortened in the English patch

The 3DS draws text into fixed boxes. Text wider than its box wraps and gets clipped, so some names and labels are shortened in this patch. **Left column = how it should read (full wording). Right column = what this patch shows.** Use it to look up a name you do not recognise. Nothing here is a mistake; it is done on purpose to fit the screen.
